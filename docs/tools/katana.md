# katana

- **Rivets** : web
- **Type** : Go (`go.lock`)
- **Source** : `github.com/projectdiscovery/katana/cmd/katana`

## Rôle
Crawler web : récupère les endpoints et URLs accessibles d'un site.

## Usage
```
katana -u https://exemple.com
```

## Exemple
```
katana -u https://exemple.com -o urls.txt
```
